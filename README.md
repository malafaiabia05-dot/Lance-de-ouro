# ⚽ Lance de Ouro

Um site dedicado ao futebol onde você pode encontrar conteúdos, história e gerenciar o seu perfil de torcedor!

## 🚀 O que tem no projeto:
- **Páginas de Login e Cadastro** para os torcedores entrarem no clube.
- **Página de Perfil** para gerenciar as suas informações e ver o acervo salvo.
- **Design responsivo** e estilizado para web.
